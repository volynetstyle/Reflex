# Reflex runtime: semantic characterization

**Baseline:** `9b21f58a35e0` (`testkit/oracle/baseline-commit.txt`): the
characterized commit `39587e93fab8` plus the F10 defect fix. Every claim below
holds for both unless marked otherwise. Sections 2–5 describe the baseline;
the status column of §6 is kept current for `dev` (a fixed finding names its
commit), so a finding marked open is open in the current sources. Optimization work compares against a
frozen bundle of the baseline (`test/oracle`); an accepted semantic fix moves
the baseline in its own commit, after its oracle divergences are classified.

## 2. State space

### Flags (`src/kernel/shape/meta.ts`)

| Bit   | Name                    | Group      | Meaning                                                              |
| ----- | ----------------------- | ---------- | -------------------------------------------------------------------- |
| 0     | `Unknown`               | evidence   | validation required                                                  |
| 1     | `Changed`               | evidence   | execution/recompute required                                         |
| 2     | `Visited`               | execution  | invalidated during execution (watchers); force marker with `Changed` |
| 3     | `Computing`             | execution  | callback (or watcher frontier validation) active                     |
| 4     | `Watcher`               | role       | sink node                                                            |
| 5     | `Scheduled`             | scheduling | host queue owns the watcher                                          |
| 6     | `Disposed`              | —          | **defined, never used** (F2)                                         |
| 7     | `WatcherCleanupPending` | watcher    | payload is an owned cleanup                                          |
| 29/30 | `Producer`/`Consumer`   | role       | DEV only; 0 in production                                            |

### Reachable flag sets at quiescent observation points

Census over 3000 generated programs (all families, both host protocols), at
every snapshot (between top-level operations):

| Role     | Observed sets                                                                                                         |
| -------- | --------------------------------------------------------------------------------------------------------------------- |
| Producer | `clean` only (125 884 observations)                                                                                   |
| Consumer | `clean`, `Changed`, `Unknown` only (1.17 M observations). Never `Unknown\|Changed`, `Visited` or `Computing` at rest. |
| Watcher  | 21 sets over `{Unknown, Changed, Visited, Watcher, Scheduled, CleanupPending}`; `Computing` never at rest.            |

Inside callbacks a consumer additionally carries `Computing`, and the
computing-subscriber path may add `Visited | Unknown` (discarded for computeds,
F1).

## 3. Transitions

| Operation                                | Effect on subscribers / node                                                                                                                                                                                                                                                                                                                                                               | Code                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| `writeProducer` (value differs)          | Direct subscribers: clean → `Changed`; non-watcher `Unknown` → `Changed` (drops `Unknown`); watcher `Unknown` → `Unknown\|Changed`; `Computing` → computing path. Transitive: clean → `Unknown`; watcher with only `Changed` gains `Unknown`. Watchers cut descent and receive one `onNodeInvalidated` unless already `Unknown` (direct phase) or already dirty (transitive phase).        | `protocol/write.producer.ts`, `stages/propagation/push_iterator.ts` |
| `writeProducer` (equal by `Object.is`)   | Nothing; settled check if idle.                                                                                                                                                                                                                                                                                                                                                            | same                                                                |
| Computing subscriber hit                 | If the edge lies in the tracked prefix (at or before `tailIn`): `Visited\|Unknown`, or `Revalidate\|Unknown` for a watcher reached transitively (F15); otherwise nothing.                                                                                                                                                                                                                  | `markComputingSubscriber`                                           |
| `advance` (recompute)                    | Clears `Visited`, sets `Computing`, tracks reads, prunes the unvisited suffix on success; on equal value → state from _pre-compute_ evidence minus `Both`; on change → payload, same state, then one-step push: subscribers without `Changed` gain `Changed` (watchers keep `Unknown`), skipping the edge owned by the active pull walker. Failure → `Changed`, prior topology edits kept. | `stages/stabilization/advance.ts`, `push_iterator_once*.ts`         |
| `readConsumer` clean                     | Returns payload; tracks the edge if a consumer is active.                                                                                                                                                                                                                                                                                                                                  | `protocol/read.consumer.ts`                                         |
| `readConsumer` dirty, `Changed\|Visited` | `advance(node, ownedParentEdge)`.                                                                                                                                                                                                                                                                                                                                                          | `stabilizeDirtyConsumer`                                            |
| `readConsumer` dirty, `Unknown` only     | `should_recompute` over incoming edges; recompute only if a dependency changed; otherwise clear `Unknown`. No inputs → treated as clean.                                                                                                                                                                                                                                                   | same, `pull_dependency.ts`, `pull_iterator.ts`                      |
| `runWatcher`                             | Clean → no-op. `Unknown` → validate the committed frontier; `Changed\|Visited` on entry force execution. Then cleanup (untracked), compute (tracked), commit cleanup, finish with `Visited` → `Unknown\|Visited` (execution obligation), `Revalidate` → `Unknown` (validation obligation), else clean. Exits that retain `Unknown` self-emit unless `Scheduled` (F15).                     | `engine/watcher.ts`, `pull_frontier.ts`, `watcher.execution.ts`     |
| `disposeWatcher`                         | Generic unlink, clear transient flags and `CleanupPending`, then run the captured cleanup.                                                                                                                                                                                                                                                                                                 | `engine/watcher.ts`                                                 |
| `disposeNode`                            | Unlink both directions, clear `compute`/`payload`; flags untouched. Later reads are unspecified (they throw `compute is not a function` for consumers).                                                                                                                                                                                                                                    | `shape/graph/disposeNode.ts`                                        |
| Context switch                           | Save outgoing registers and DEV frame, load incoming; epoch only moves forward.                                                                                                                                                                                                                                                                                                            | `kernel/context*.ts`                                                |

## 4. Invariant inventory

Each invariant lists its evidence: **P** proof sketch, **T** targeted test,
**O** oracle/census.

| Id  | Invariant                                                                                                                                                                                                                                                                                    | Evidence                                                   |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| I1  | A producer never carries evidence bits. Push only marks `edge.to`; no supported operation links an edge into a producer.                                                                                                                                                                     | P, O (census)                                              |
| I2  | At rest a consumer is exactly one of `clean`, `Unknown`, `Changed`. Direct push replaces `Unknown` by `Changed`; transitive push only marks clean nodes; `advance` and validation clear both.                                                                                                | P, O                                                       |
| I3  | `Computing` and `Visited` never survive a completed top-level operation on a consumer.                                                                                                                                                                                                       | O                                                          |
| I4  | Watcher evidence within one unsettled wave merges by bitwise OR (V5).                                                                                                                                                                                                                        | T (`watcher/algebra.test.ts`)                              |
| I5  | `cleanupUnvisitedSources` always receives a non-empty suffix: both callers require `tailIn !== lastIn`.                                                                                                                                                                                      | P (F4)                                                     |
| I6  | Every slow-path entry of `resolveTrackedRead` follows a failed check of the same expected edge, so the default strategy's suffix-head hit (R0) is unreachable through it.                                                                                                                    | P (F5), O (never hit)                                      |
| I7  | Obsolete since H2: `resolveTrackedRead` has no `allowSlowPath` parameter; the slow strategy is always allowed.                                                                                                                                                                               | P (F3)                                                     |
| I8  | Validation never re-delivers its own watcher. The pull walker passes the owned parent edge to `advance`, which skips it; any other edge into the validating watcher is marked `Changed` without delivery because `Computing` certifies ownership (F17). Before F17 this held only for trees. | T (`runtime.scheduled-delivery`), P                        |
| I9  | Walker stacks restore their high-water mark and clear owned slots on every exit, including throws and nested domains.                                                                                                                                                                        | T (`runtime.walker-stack-stats`, `runtime.domain-walkers`) |
| I10 | The tracking epoch is monotonic across context switches (one kernel clock).                                                                                                                                                                                                                  | T (`runtime.context-registers`)                            |

## 5. Hidden preconditions

| Id  | Precondition                                                                                                                                                                                                                                                      | Relied on by                                                                                                                                                                                                                                                             |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| H1  | `advanceCore` derives the final state of a computed from its **pre-compute** evidence and discards marks set during compute.                                                                                                                                      | The pull read path (`should_recompute` → `advance(node)` without a skip edge) marks the reading, computing consumer `Changed` through `push_iterator_once`; that mark is harmless only because H1 discards it. Changing F1 requires also skipping the reader edge there. |
| H2  | Hosts either claim watchers (`Scheduled`) or tolerate duplicate deliveries. Write-time push suppresses re-delivery to an already-`Unknown` watcher; advance-time push suppresses it for `Scheduled` watchers and for a watcher in its own run (`Computing`, F17). | Scheduler dedup, oracle host protocols                                                                                                                                                                                                                                   |
| H3  | Graphs are acyclic. Cycle detection exists only in DEV.                                                                                                                                                                                                           | Pull walkers terminate                                                                                                                                                                                                                                                   |
| H4  | Invalidation hooks enqueue only (DEV-enforced). Production tolerates nested writes from hooks (`write.propagation.nested`), propagating synchronously inside the outer wave.                                                                                      | Push re-entrance via the shared stack                                                                                                                                                                                                                                    |

## 6. Findings

| Id  | Kind                                           | Finding                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Action                                                                                                                                                                                                                                                                                                                 |
| --- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1  | Defect candidate, contract open                | A write to an already-read dependency during a computed's own evaluation is lost: the computed stays clean with a stale value (`c` returns `0` while its source is `1`). `INVARIANTS.md` §2 says accepted invalidation "adds `Visited \| Unknown`", which holds for watchers but is overwritten for computeds (H1). The semantic contract explicitly leaves writes during execution undecided. Liveness consequence (F15 oracle): a watcher that reads such a computed through a not-yet-tracked edge keeps the stale value and is never re-delivered.                                                                                                                                                                                        | Owner decision. Not changed by optimization work; the oracle pins current behavior.                                                                                                                                                                                                                                    |
| F2  | Dead code                                      | `Disposed` (bit 6) is exported and never read or written; `DISPOSE.md` states there is no disposed bit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Removal candidate (internal export).                                                                                                                                                                                                                                                                                   |
| F3  | Dead parameter                                 | `allowSlowPath = false` was reachable only from one direct resolver test.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Removed with H2 (`KERNEL_AUDIT.md` §12).                                                                                                                                                                                                                                                                               |
| F4  | Unreachable branch                             | Empty-suffix early exit in `cleanupUnvisitedSources`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Simplification candidate (keep as DEV assertion).                                                                                                                                                                                                                                                                      |
| F5  | Unreachable via API                            | Suffix-head hit (R0) in the default tracking strategy.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Keep: strategies are public.                                                                                                                                                                                                                                                                                           |
| F6  | DEV asymmetry                                  | Direct-phase watcher invalidation emits a DEV debug event without a hook; the transitive phase requires a hook. DEV diagnostics only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Record.                                                                                                                                                                                                                                                                                                                |
| F7  | Duplication                                    | `countIn`/`countOut` exist twice (PROFILE only).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Cleanup candidate.                                                                                                                                                                                                                                                                                                     |
| F8  | Refuted suspicion, **reopened by F17**         | Validation does not re-deliver its own watcher (I8). The argument covered only the owned parent edge; F17 is the counterexample through a side edge.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | None.                                                                                                                                                                                                                                                                                                                  |
| F9  | Asymmetry, contract open                       | An `Unknown` consumer without incoming edges is recomputed when reached as a dependency (`pull_frontier`, `pullDependencyDirty`, `pull_iterator` advance it as a leaf) but treated as clean when read as the root (`stabilizeDirtyConsumer` requires `firstIn !== null`). Reachable only after disposing a live upstream producer, which leaves the reader `Unknown` with no inputs.                                                                                                                                                                                                                                                                                                                                                          | Record; pinned by the oracle. Not an optimization target.                                                                                                                                                                                                                                                              |
| F10 | **Defect, fixed** (`9b21f58`)                  | Edge creation coerced the stamp to int32 while reuse stored the uint32 epoch, so from epoch 2^31 one pass carried two stamps. The version fallback of the bounded prefix scan then linked a duplicate edge for a duplicate read beyond 32 edges, and the first-outgoing probe moved an accepted edge. Values and notifications were unaffected. Oracle: 10 of 4000 runs diverged, all topology-only.                                                                                                                                                                                                                                                                                                                                          | Fixed (`>>> 0`), regression test in `runtime.tracking-stamp.test.ts`, baseline re-pinned.                                                                                                                                                                                                                              |
| F12 | **Defect, fixed** (`bb5fc5f`)                  | DEV `subtle.stackStats().propagate.peak` was always 0: the propagation walker never recorded its stack height.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | DEV diagnostics only; production unchanged.                                                                                                                                                                                                                                                                            |
| F13 | **Defect, fixed** (`190a09e`, #52)             | When a pass stamp equals a stale stamp on a suffix edge (epoch rewound by `setTrackingStamp`, or wrapped exactly onto it), the version fallback of the duplicate test takes the stale edge for an accepted one; the read is dropped and cleanup unlinks the edge, so the dependency is lost. Reproduced on shipped code (`KERNEL_AUDIT.md` §14).                                                                                                                                                                                                                                                                                                                                                                                              | The tracking clock only moves forward and a located edge is in the prefix iff it carries the pass stamp (INV-T3, `KERNEL_AUDIT.md` §14). The baseline keeps the defect: the oracle accepts the difference as class F13 (`testkit/oracle/verdict.ts`); regressions in `test/differential/runtime.epoch-collision.test.ts`. |
| F15 | **Defect, fixed**                              | A watcher invalidated transitively during its own validation or execution kept `Unknown` without `Scheduled`; later pushes merged into `Unknown` silently, so the watcher never ran again (scheduler-delivery liveness, all host strategies).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `Revalidate` (validation-only obligation) and self-delivery from `runWatcherCore`. R2 restated; baseline divergence classified by the liveness invariant.                                                                                                                                                              |
| F16 | **Defect, fixed** (`ab5ec15`)                  | A cleanup that writes through a dependency and then throws was recovered to idle while that dependency stayed dirty. Push stops at a dirty computed, so the watcher was unreachable through it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Cleanup failures use the same dirty-dependency scan as callback failures and keep `Unknown`; the scheduler retries on its next drain.                                                                                                                                                                                  |
| F17 | **Defect, fixed**                              | A watcher was delivered to the host again during its own validation. The scheduler releases `Scheduled` before `runWatcher`, and `pull_frontier` holds `Computing` without `Changed`. A pull proof that recomputed a node with an edge into the watcher other than the walker's owned edge (watcher reads `d = g(a)` before `a`) marked the watcher `Changed` through `push_iterator_once` and called `onNodeInvalidated`. The pass already consumes that evidence, so the queued copy ran as a clean skip: 2 deliveries and 2 `runWatcher` calls per write for 1 callback, depending only on read order. A validation failure in that pass queued the watcher into the same drain and failed it twice. Oracle: 2 of 2000 generated programs. | `Computing` joins `Scheduled` as the delivery guard in `push_iterator_once`; `Changed` is still recorded. Reentrant writes keep the R2 path. R10; regressions in `runtime.scheduled-delivery.test.ts`; baseline divergence classified as an own-epoch delivery.                                                        |
| F18 | **Defect, open** (contract decided 2026-10-28) | A watcher attempt that fails on the first read of a throwing computed retains no retry trigger for that computed: the runtime treats a read that throws as no evidence at all, so the retry set holds only the committed and partial successful reads. Once the computed's cause is repaired, the watcher is never retried, whether the failing read was its initial run or a newly entered branch. Spec and Reflex agreed until the spec adopted C4: a failed read is no committed dependency but is causal retry evidence.                                                                                                                                                                                                                  | SpecRuntime rule 4 follows C4 (`SEMANTIC_CONTRACT.md`); active divergence in `test/differential/catalog/active.ts`. The runtime fix changes the bundle and is pending; afterwards the entry moves to `historical.ts` and a revert of the fix joins the holdout mutants (`testkit/oracle/faults.ts`).                      |

## 7. Coverage

The oracle corpus reaches 102 of the 109 `projection.semantic.*` branch events
(`testkit/oracle/branch-coverage.json`). Unreached: 4 DEV-only or path-observer
events, and F3/F4/F5. All 8 seeded single-fault mutants are killed within 2000
seeds.
